## 프로젝트 소개

### 개인 연구 및 프로젝트 포트폴리오 웹사이트

AI Security와 Graph Machine Learning을 중심으로 진행한 연구 경험과 프로젝트, 논문 및 학회 활동을 체계적으로 소개하기 위해 개발한 개인 포트폴리오 웹사이트입니다.

기존의 단순한 이력서 형태의 포트폴리오에서 벗어나 프로젝트의 **문제 정의 → 구현 → 주요 기여 → 트러블슈팅 → 결과 → 배운 점**을 하나의 흐름으로 보여주는 연구 중심의 포트폴리오를 목표로 제작하였습니다.

특히 서로 다른 성격의 프로젝트를 일관된 디자인 시스템 안에서 표현하면서도, 각 프로젝트의 기술적 특징과 연구 성과를 충분히 전달할 수 있도록 **재사용 가능한 컴포넌트 구조와 프로젝트 데이터 기반 렌더링 방식**을 적용하였습니다.

▪️ 연구 및 프로젝트 경험을 효과적으로 전달할 수 있는 포트폴리오 구축<br>

▪️ 긴 연구 프로젝트 페이지에서도 원하는 정보를 빠르게 탐색할 수 있는 UX 제공<br>
